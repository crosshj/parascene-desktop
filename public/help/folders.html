Folders

Folders live on the Library board. A regular folder is a group you made. A project folder is tied to one project. They are still decoupled: making a Library folder does not create a project, and making a project does not reuse a regular folder you already had.

Regular folder

  1. Open Library.
  2. Select one or more stills or clips.
  3. In the sidebar under Selection, click New folder….
  4. Name it (or leave Untitled folder) and click Create.

The new folder is regular — it has no project. Add more files later with Add to folder…. Inside a folder, Remove from folder takes selected items back off that group. Delete folder removes the folder, not the media.

Project folder

New project creates its own project folder and binds it. You can also select files in Library and click New project… — those files move into the new project folder.

A project folder is the project’s file group on this device. Adding files to it (Add to folder…) files them into that project. You cannot file the same items into two project folders.

Delete project does not delete the media. The bound folder becomes a regular folder with the same name and members. If a project folder is left locked after the project is gone, Library offers Release as regular folder.

Where they differ

  • Regular folder: grouping only. No Director, no Editor, no generate target.
  • Project folder: created with the project, shown as the project’s board pile, used as the home for assets you generate in that project.
  • Sync newest updates creations. Folder membership is a separate Sync folders pass.
