Generate speech and music

We'll stay in a new project and make one spoken line with Text to Speech, Parascene. Then we'll add a spoken file from disk and put the generated line on A1 and the file on A2, with a little space between them. Publisher keeps both tracks in the mix.

One spoken line

  1. Click Editor in the top bar.
  2. In Assets (left), click the + tile labeled Add asset.
  3. Choose Text to Speech.
  4. Under System, choose Parascene (Credits · Creations).
  5. Under Model, pick Gemini 3.1 Flash TTS. Voice Kore.

We typed this line.

The night market is still open.

A second spoken clip

  1. In Assets, click Add from disk… and pick a spoken file you already have.

Text to Music is the same Add asset path if you want a score instead. We used a spoken file so both clips are talk, on two tracks.

Dual audio tracks

  1. Drag the generated line onto A1 at the start.
  2. Turn on the second audio lane, then drop the file from disk on A2 a little after the first line ends.
  3. Open Publisher and render. Both tracks are in the file — the space between them stays quiet.
