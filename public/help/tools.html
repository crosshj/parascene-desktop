Local tools

Parascene Desktop uses a few programs on this computer. They are not inside the app. Install them here, then confirm Settings can see them.

See what the app can find

  1. Open the account menu (your avatar in the top bar).
  2. Click Settings.
  3. Scroll to Local tools.

Each tool shows ready or missing, and the path when it is found. If it is missing, Settings prints the install command for this computer. After you install something, click Re-check (or quit and reopen the app). A tool on your PATH that still says missing is not visible to the app yet.

A terminal can see a tool while the app cannot. GUI apps often have a thinner PATH than your shell. Re-check is the truth for Parascene, not which or where alone.

FFmpeg — required

FFmpeg is a hard requirement for most media work: Editor preview and thumbs, reverse, merge, Publisher render, audio slice, and Lab isolate / extend. Library browse and Sync can run without it. Preview, thumbs, and render cannot.

  1. Install Homebrew if you do not have it, then run:
brew install ffmpeg
ffmpeg -version
  1. In Terminal or PowerShell:
winget install ffmpeg
ffmpeg -version

Then Settings → Local tools → Re-check. FFmpeg should say ready.

Demucs — optional

Demucs splits vocals from a mix (Python + PyTorch). Lab Vocals / slice and a2v need it for a vocals stem. Without Demucs you can still slice the full mix. a2v stays blocked until Demucs is ready.

Needs Python 3.9+ on PATH. First install downloads PyTorch (large; needs network). 

python3 -m pip install --user demucs

The command usually lands in ~/Library/Python/3.x/bin or ~/.local/bin. Put that folder on PATH, or use Settings → Local tools → Install demucs so the app runs the same pip install and looks in those folders even when the GUI PATH is thin. 

python -m pip install --user demucs

Use Python from python.org with Add python.exe to PATH. Avoid the Microsoft Store stub under WindowsApps. Scripts usually land in %APPDATA%\Python\Python3x\Scripts. Settings → Local tools → Install demucs runs the same pip install and looks there.

Re-check until Demucs says ready.

Whisper — optional

Local Whisper transcribes audio for Lab Lyric align. You can use the OpenAI Whisper API instead. Mapping lyrics onto segments still needs an OpenAI key in Settings. Local Whisper is not required for generate, Sync, or Library. 

python3 -m pip install --user openai-whisper
python3 -m pip show openai-whisper
python -m pip install --user openai-whisper
python -m pip show openai-whisper

The app looks for the package and the whisper command. It does not require whisper --help to succeed — that import is slow and a common false-negative. If the shim is off PATH but the package is installed, the app runs python -m whisper.

Re-check until Whisper says ready.

If Settings still says missing

  • Quit the app and reopen it after changing PATH.
  • Use a current python3 from python.org or Homebrew, not an old system Python. Confirm where python is not under WindowsApps.
  • Demucs and Whisper need disk and network — the first install is multi-GB.
  • If Demucs errors about NumPy, python3 -m pip install --user 'numpy<2' python -m pip install --user "numpy<2"
