Generate an image

The first generate path is Text to Image on Parascene (account credits, a Creation in your library). You do this from the Editor of an open project — not from Library, and not from Direct to Blue or Replicate.

Open Editor

  1. Create or open a project. New project lands on Director.
  2. Click Editor in the top bar.
  3. In Assets (left), click the + tile labeled Add asset.

Text to Image on Parascene

  1. Choose Text to Image (Prompt → still).
  2. Under System, choose Parascene (Credits · Creations). Skip Direct to Blue and Replicate — those need keys in Settings and stay local-only.
  3. Write a prompt.
  4. Under Model, pick a cheap SD 1.5 option (labels look like sd15: lofi_V2pre). Those cost a fraction of a credit.
  5. Click Generate and wait. The job can take a while.

The still uses the project aspect ratio from Director. When it finishes it lands in this project’s assets and in Library (and in the project folder). Image to Image, video intents, and other systems are later paths.
