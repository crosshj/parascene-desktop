This computer and the cloud

You signed in with a Parascene account. The website keeps that account and the Creations on it. This app is a studio on this computer. Library is the pile of files here.

Some Library files are copies of website Creations. Some never go to the website. A project is only on this computer.

On this computer

  • Library — the stills, clips, and audio you work with. Add from disk… stays here.
  • Projects — the document you edit (Director, Editor, timeline, aspect). Not on the website. Another computer will not see it after Sync.
  • Settings keys, Labs, preview quality, and local tools.

On Parascene

  • Your account — that is why you clicked Log in.
  • Creations you made on the website, or here with System Parascene (credits).
  • Website folders for those Creations.

How they meet

  • Sync copies website Creations onto this computer, then previews and full files. It also drops rows the website deleted.
  • System Parascene writes a Creation on the account and a file in Library.
  • System Direct to Blue or Replicate writes a file in Library only. The website does not get a Creation.
  • Folder grouping can travel both ways (Sync folders). If they disagree, you pick This desktop or Cloud.

Sync does not copy a project document. Open the same Creations on another machine and you still make a new project there.

What delete does

  • Delete project removes the document on this device. Library files stay. Website Creations stay.
  • Delete a Creation on the website, then Sync — that row leaves Library here.
  • Delete folder removes the group, not the files.
