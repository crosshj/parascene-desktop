Sync

You signed in with a Parascene account. The website keeps that account and the Creations on it. This app is a studio on this computer. Library is the pile of files here.

Sync pulls this account’s cloud creations onto this computer and removes rows that were deleted in the cloud. You do this from the Sync tab — not from Library. A project stays on this computer.

On this computer

  • Library — the stills, clips, and audio you work with. Add from disk… stays here.
  • Projects — the document you edit (Director, Editor, timeline, aspect). Not on the website. Another computer will not see it after Sync.
  • Settings keys, Labs, preview quality, and local tools.

On Parascene

  • Your account — that is why you clicked Log in.
  • Creations you made on the website, or here with System Parascene (credits).
  • Website folders for those Creations.

Sync newest

  1. Click Sync in the top bar.
  2. Wait until the status says Ready.
  3. Click Sync newest.
  4. Watch the counts: Creations, Previews, Media, Folders, and On disk.

Newest is the usual step. It updates recent creations; it does not hammer the full catalog.

Previews, media, and folders

After the catalog is current, extra buttons appear only when work remains:

  • Cache N previews — download thumbnails so Library cards show pictures.
  • Cache N media — download the full files you will edit or generate from.
  • Sync N folder changes — pull cloud folders and push pending local folder edits.

Folder sync is a separate step from Sync newest. A catalog can be current while folders are still empty or still waiting to upload.

What generate writes

  • System Parascene writes a Creation on the account and a file in Library.
  • System Direct to Blue or Replicate writes a file in Library only. The website does not get a Creation.

Conflicts

If a folder disagrees with the cloud, Sync lists the conflict. Choose This desktop or Cloud for each one, then Apply resolutions and retry.

What delete does

  • Delete project removes the document on this device. Library files stay. Website Creations stay.
  • Delete a Creation on the website, then Sync — that row leaves Library here.
  • Delete folder removes the group, not the files.

Advanced

Open Advanced only when newest is not enough:

  • Sync full catalog — rebuild the whole catalog. Slow; not the everyday button.
  • Sync folders — same folder pass as above, on demand.
  • Sync group members — repair grouped creations.
  • Repair thumbs — rebuild mismatched previews.

The path under Advanced is this account’s folder on disk. Recent jobs lists what just ran.
